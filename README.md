## Overview

This repository is the companion to the [AI ML Made Easy](https://www.youtube.com/@DevOpsMadeEasy) YouTube channel. It provides structured, self-paced courses covering AI, Machine Learning, and Generative AI — from foundational concepts to hands-on tooling.

Each course is organized under `courses/` with its own README, lesson notes, and links to the corresponding YouTube videos.

Each lesson is designed to fit within **15–20 minutes** and help learners move from fundamentals to practical AI application building.

## Who This Is For

- Beginners starting from zero who want a clear learning path
- Developers transitioning into AI/ML engineering
- Practitioners who want structured, project-oriented courses on modern AI tooling

## Learning Goals

By completing the courses in this repository, learners will be able to:

- Understand AI, ML, DL, GenAI, and LLM fundamentals
- Run and experiment with local LLMs
- Build simple prompt-based and retrieval-based applications
- Understand when to use LangChain, LlamaIndex, LangGraph, and n8n
- Design chatbots, agents, workflows, and MCP-based integrations
- Use AI-powered developer tools like Claude Code effectively
- Move from conceptual knowledge to small real-world AI projects
