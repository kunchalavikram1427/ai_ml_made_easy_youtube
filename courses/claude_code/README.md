# Claude Code Course

Learn how to use Claude Code effectively for day-to-day software engineering, repo navigation, debugging, refactoring, and agent-assisted development workflows.

## Course Overview

This course is designed as a practical, project-oriented path for developers who want to use Claude Code as an engineering assistant rather than just a chat interface.

Each lesson can later be mapped to a short YouTube video, demo, or hands-on walkthrough.

## Learning Goals

- Understand what Claude Code is and where it fits in a developer workflow
- Use Claude Code to explore unfamiliar repositories faster
- Apply Claude Code to debugging, refactoring, testing, and documentation tasks
- Build safe habits for reviewing, validating, and accepting AI-generated code changes
- Design repeatable workflows for solo development and team usage
