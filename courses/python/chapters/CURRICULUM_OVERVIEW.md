# Python for AI - Complete YouTube Course Curriculum

## Course Overview

A comprehensive Python programming course designed for beginners and intermediate learners, progressing from fundamental concepts to advanced libraries and real-world applications. The course consists of **31 videos** organized in 5 phases.

**Target Audience:** Beginners to intermediate Python learners who want to build practical skills for automation, data analysis, web development, and AI integration.

**Course Format:** Each video has a corresponding Jupyter notebook with detailed explanations, code examples, and hands-on exercises.

## How to Use This Curriculum

1. **Follow the order** — Each topic builds on previous ones
2. **Watch the video** — Get the conceptual overview
3. **Open the Jupyter notebook** — Follow along with code
4. **Complete the exercises** — Practice reinforces learning
5. **Build the mini-project** — Apply knowledge to real problems

## Prerequisites

- A computer with Python 3.10+ installed (covered in Video 02)
- VS Code or any code editor (covered in Video 02)
- Basic computer literacy
- Curiosity and willingness to practice!
